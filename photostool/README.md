# photos.json 编辑器

图集数据的本地编辑工具：纯静态页（HTML/CSS/JS），不需要构建、不需要联网、不依赖任何库。
读写的就是仓库根目录的 `photos.json`。

## 打开

浏览器不允许 `file://` 页面用 `fetch` 读同目录文件，所以起一个本地静态服务器再打开：

```bash
cd <仓库根目录>
python -m http.server 8123
```

然后访问 <http://127.0.0.1:8123/photostool/>。

打开后可以直接：

- 左侧「打开」选择 `photos.json`；
- 「从站点载入」抓取同级/上级的 `photos.json`（这就是服务器的作用）；
- 或者把 JSON 文件拖进窗口。

## 能做什么

| 操作 | 说明 |
|---|---|
| 载入 | 打开文件、从站点载入、粘贴 JSON、拖拽文件 |
| 编辑分类 | 改分类名，改完自动合并同名分类 |
| 编辑图片 | 每行 = 一个 URL + 一个说明，可搜索、按 URL 状态筛选 |
| 增删排序 | 新增图片、删除图片、上移/下移、新增/删除分类 |
| 实时校验 | 空 URL、重复 URL、不是常见图片扩展名、坏图（缩略图加载失败）都在行上和状态栏标出 |
| 预览 | 生成将要写入的 `photos.json` 原文（与现有排版一致：2 空格缩进、每张图一行） |
| 撤销 | 最多 120 步，编辑内容自动存到 `localStorage`，关掉页面再回来还在 |
| 导出 | 复制到剪贴板、下载 `photos.json`、另存到本地文件 |

## 保存回仓库

浏览器默认不能直接改写磁盘文件，两种方式：

1. **下载覆盖**：点「下载」，用它替换根目录的 `photos.json`，然后提交。
2. **直接保存**（Chrome / Edge）：首次用「打开」选择 `photos.json` 时授权写入，之后点「保存」直接写回原文件。

保存前看一眼状态栏：存在空 URL 或重复 URL 时会给出提示，写出去的 JSON 仍合法，但图集页面会过滤掉空 URL。

## 数据格式

```json
[
  {
    "category": "分类名",
    "photos": [
      { "url": "image/xx.jpg", "caption": "说明" }
    ]
  }
]
```

也接受平铺写法 `[{ "url": "...", "caption": "...", "category": "..." }]`，保存时会统一成分类结构。

## 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl/⌘ + S` | 保存 |
| `Ctrl/⌘ + O` | 打开文件 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销 / 重做 |
| `Ctrl/⌘ + P` | 预览 JSON |
| `Ctrl/⌘ + F` 或 `/` | 聚焦搜索 |

## 部署

本目录不发布：根目录 `_config.yml` 里已把它排除出 GitHub Pages 构建。
改完 `photos.json` 推送 `main`，图集页面就会用新数据。

## 自检

```bash
node photostool/test-core.cjs
```

覆盖解析、序列化（含与现有文件的逐字节往返一致性）、校验与统计。
